# Miami Emergency Operations Center

## Project Overview

This project simulates the Azure infrastructure for a Miami Emergency Operations Center (EOC).

The EOC requires secure, reliable, and scalable cloud infrastructure to support emergency personnel, communication systems, operational applications, and critical data during normal operations and disaster scenarios.

## Objectives

- Design a secure Azure network architecture
- Deploy infrastructure using Infrastructure as Code with Bicep
- Implement identity and access managment
- Configure monitoring and alerting
- Implement backup and disaster recovery capabilities
- Apply Azure security and governance best practices
- Demonstrate practical Azure Administrator skills

## Azure Services 

The project will incorporate Azure services including:

- Azure Virtual Network
- Subnets
- Network Security Groups
- Microsoft Entra ID
- Azure Virtual Machines
- Azure Storage
- Azure Key Vault
- Azure Monitor
- Log Analytics
- Azure Backup
- Azure Site Recovery
- Azure Resource Groups
- Azure Policy
- Azure Role-Based Access Control (RBAC)

## Project Architecture

The EOC environment will be designed with separate network segments for administrative systems, emergency operations, application workloads, and management services.

Infrastructure will be deployed using Bicep templates to demonstrate repeatable and automated Azure deployements.
