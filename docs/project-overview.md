# Miami Emergency Operations Center

## Project Overview

This project simulates the Azure infrastructure for Miami Emergency Operations Center (EOC).

The EOC requires secure, reliable, and scalable cloud infrastructure to support emergency personnel, communication systems, operational applications, and critical data during normal operations and disaster scenarios.

## Objectives

- Design a secure Azure network
- Implement identity and access management
- Deploy virtual machines for emergency operations
- Configure secure storage for operational data
- Implement monitoring and alerting
- Apply Azure security and governance controls
- Design backup and disaster recovery capabilities
- Automate infrastructure deployment where appropriate

## Azure Services

The project will use:

- Azure Resource Groups
- Microsoft Entra ID
- Azure Virtual Network
- Subnets
- Network Security Groups
- Azure Virtual Machines
- Azure Storage
- Azure Monitor
- Azure Backup
- Azure Key Vault
- Azure RBAC
- Azure Policy
- Azure Resource Locks
- Azure Cost Management
- Azure CLI / PowerShell
- Bicep

## Scenario

The Miami Emergency Operations Center must remain operational during severe weather, hurricanes , infrastructure failures, and other emergency situations.
The Azure environment will be designed with security, availability, monitoring, and disaster recovery in mind.
